```text

        ↓
Vendor Creation
        ↓
Request for Quotation
        ↓
Vendor Quotation
        ↓
Vendor Comparison
        ↓
G/L Accounting
        ↓

        ↓

        ↓

        ↓
Invoice Verification – MIRO
```
